Data Directory Notice

The methylation and clinical datasets analyzed in this study are not included in this repository due to access restrictions. 

To reproduce the results, researchers must obtain approved access to the following cohorts directly from dbGaP:
- Framingham Heart Study (FHS): dbGaP accession phs000007
- Women's Health Initiative (WHI): dbGaP accession phs000200

Once access is granted, the unnormalized datasets should be placed in this folder before running the pipeline.
